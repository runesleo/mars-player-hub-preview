Start Here

Project Mars，第一次只需要看懂这一页。

目标不是让你马上放大仓位，而是让你知道自己在花什么、等什么、收什么，以及下一步为什么这样做。

官方规则优先如果页面参数与游戏当前 UI 不一致，以官方当前 UI 为准。

先选角色：钻工（Driller）不等于地块主（Plot Owner）。

轻入口

钻工（Driller）

花 DRILL 部署钻机（Rig），等待后收矿（Collect），拿 Base DRILL、矿石（Ore）和其他当前启用的材料/奖励。你可以在别人的开放地块（Open Plot）上开始，不必先买地。

重资本

地块主（Plot Owner）

持有地块（Plot）、用矿石（Ore）升级，提高权重（Weight）和地块主分成（Owner Cut），并管理是否开放给其他钻工。买地块不是新人的强制第一步。

Core terms

六个核心词先搞懂。

DRILL

Paid Rig 的主要工作资金，也用于部分建筑/市场。不要把全部 DRILL 都当“利润”。

钻机（Rig）

你选择的作业档位。成本、持续时间和矿石（Ore）概率不同。

矿石（Ore）

升级材料，也可以在市场交易。升级储备和可出售库存要分开。

地块（Plot）

L1–L20 的土地资产。升级会提高权重（Weight）与地块主分成（Owner Cut）。

赛季（Epoch）

排行榜奖励周期。当前奖励可能是积分/材料，不应自动折算成未来代币现金价值。

OIL / 矿浆（Slush）

独立材料/奖励层。OIL 保留官方英文；Slush 可在中文群里辅助称为“矿浆”。不要直接按现金利润记账。

中文术语

群里怎么说，官方页面怎么写。

本站不做整页中英双语。第一次出现用“中文（官方英文）”，后面优先中文。这样聊天顺口，回官方 UI 也能对得上。

专有资产名如 DRILL / OIL / Core Blue / New Horizons 保留英文，不为了中文化而硬翻译。

First cycle

新人第一轮照这个顺序。

确认唯一入口

从 project-mars.app 进入，钱包切到 Robinhood Chain，保留网络 gas。

先决定“练手”还是“放大”

第一次更适合用低档钻机（Rig）理解完整流程，而不是直接用最大 Tier 学习。

找空闲地块（Plot）

有自己的地块（Plot）可以自挖；没有地块，可以找允许访客的开放地块（Open Plot）。

部署钻机（Plant）后记录成本

记录花掉多少 DRILL、Rig Tier、开始时间。付费钻机（Paid Rig）成本是你后面算现金账的基准。

到点收矿（Collect）

记录收到的 base DRILL、Ore、Slush/OIL 等，不要只盯账户总余额。

再决定下一轮

先看工作资金是否够、Ore 是否要留给升级，再决定继续部署（Replant）、买矿、卖矿或停。

一定要分“两本账”。

现金账

本轮可兑现价值：base DRILL + 可执行 Ore 价值 + 已验证 bonus − Rig 成本 − gas。未兑现积分、未知用途奖励不硬算现金。

成长账

Ore 是否帮助你升级、减少未来购买成本、解锁更高 weight/cut。成长价值可能解释为什么某轮现金账不漂亮但仍有进度。
